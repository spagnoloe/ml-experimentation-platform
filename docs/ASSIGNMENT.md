# Take-Home Assignment: ML System Improvement

**Time expectation:** ~4 hours.

You've inherited a notebook from a junior data scientist who was prototyping a regression model on a public dataset.

Your job is to build a system that:
- Enables the data scientist to run, track, and compare experiments, and identify the best-performing model
- Exposes the chosen model by the data scientist to other teams and systems, allowing the data scientist to easily switch models
- Includes a minimal UI to let the data scientist test the exposed model (UI polish will not be evaluated)

You have significant flexibility in how you approach this assignment. You are not required to use or build directly on top of the original notebook or code produced by the junior data scientist. You may refactor, redesign, or reimplement components as needed, and you may use any tools, frameworks, or structure you consider appropriate.

The expectation is to build a proof of concept that runs locally. There is no need for a production-ready solution yet, but the solution should be designed so it can evolve into a production-ready system without requiring major rewrites.

Additionally, include an architecture design for the production version of the system describing how your system would work in a production environment.

Submissions will be evaluated on how effectively they address the system requirements above, the quality and maintainability of the implementation, the reasoning behind design decisions, and clarity of communication. We value depth of reasoning over completeness — a well-executed subset is better than a rushed full submission.

Please deliver the solution via a private GitHub or Bitbucket repository.

## Dataset Description

The dataset used in this assignment is the [California Housing dataset](https://scikit-learn.org/stable/datasets/real_world.html#california-housing-dataset). Refer to the scikit-learn documentation for details on the dataset and available features.
